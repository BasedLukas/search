speech_to_text

A lightweight, efficient speech-to-text system based on OpenAI Whisper model

Get Started

Quick Start Guide

1. Clone the Repository 
git clone https://example.invalid
cd speech_to_text
2. Create and Set Up the Virtual Environment 
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
3. Run the Application 
python main.py
